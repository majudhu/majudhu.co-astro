# [My personal blog website](https://majudhu.co)

Re-written using [Astro](https://astro.build), [Tailwind CSS](https://tailwindcss.com) and formatted with [Prettier](https://prettier.io) via [prettier-plugin-astro](https://github.com/withastro/prettier-plugin-astro).

## Mirrors

- [Vercel](https://majudhu.vercel.app)
- [Cloudflare](https://majudhu.pages.dev)
- [Surge](https://majudhu.surge.sh)
- [Render](https://majudhu.onrender.com)
- [GitHub Pages](https://majudhu.github.io/majudhu.co-astro)
- [Deno Deploy](https://astro.majudhu.deno.net)

_[Repo of old website](https://github.com/majudhu/majudhu.co) made from a bootstrap 3 [template](https://www.free-css.com/free-css-templates/page243/tinker)_

## Commands

All commands are run from the root of the project, from a terminal:

| Command              | Action                                                                                                 |
| :------------------- | :----------------------------------------------------------------------------------------------------- |
| `pnpm install`       | Installs dependencies                                                                                  |
| `pnpm run dev`       | Starts local dev server at `localhost:4321`                                                            |
| `pnpm run build`     | Builds the static site to `./dist/` (for Vercel, Cloudflare, Surge, Render, GitHub Pages, Deno Deploy) |
| `pnpm run preview`   | Previews the static build locally                                                                      |
| `pnpm run fmt`       | Formats the codebase with `prettier`                                                                   |
| `pnpm run fmt:check` | Checks formatting without writing (CI-friendly)                                                        |
| `pnpm run astro ...` | Runs Astro CLI commands like `astro add`, `astro check`                                                |
